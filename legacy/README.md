# Nightreign Cheat Sheet

Vibe coded boss weaknesses for Elden Ring: Nightreign. Type an expedition, or a night boss you just fought.

## Running it

```bash
npm install
npm run dev
```

```bash
npm test         # search and dataset checks
npm run build
npm run verify   # what the page actually renders — needs a server up
npm run audit    # layout, 360px to 3440px — needs a server up
```
